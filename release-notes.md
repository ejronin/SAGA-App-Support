## Version 1.0.2

**Status:** LIVE — Autodesk Design and Make Marketplace  
**Platform:** Windows  
**Host application:** Autodesk Fusion  
**Marketplace:** [SAGA — Assembly Guide Authoring](https://marketplace.autodesk.com/apps/ba97abb7-47a9-461d-a69e-a31130964c5a)

SAGA 1.0.2 is the current public Marketplace release of Shawn's Assembly Guide Authoring for Autodesk Fusion.

### Included in the 1.0.2 release

- Local, editable SAGA project folders
- Assembly-step capture from the active Fusion view
- Opaque and transparent-background PNG captures
- Written step instructions and structured information, caution, warning, do-not, inspect, and check notices
- Arrows, leaders, alignment lines, labels, visual markers, and BOM-linked part callouts
- Step ordering plus product and manual revision information
- Optional configuration paths with linked branch instructions
- Parts, hardware, tools, consumables, and bill-of-materials support
- **Check Project** validation before publication
- Compiled PDF publication with optional cover, contents, links, and bill of materials
- Customer branding, including a project logo and finished-product cover image
- Autodesk Marketplace entitlement verification for both trial and purchased access
- Marketplace **Free 30-Day Trial** with full SAGA functionality, no output watermark, and customer branding available
- Up to 24 hours of SAGA-specific cached access after a previous successful Autodesk entitlement check when Autodesk's entitlement service is temporarily unavailable; this duration is SAGA behavior, not an Autodesk-required period

### Release limits

- Windows only
- Manual add-in startup by default
- One configuration split with up to five paths
- No nested configuration splits
- No SAGA cloud account or SAGA cloud project-storage service
- No product analytics or automatic crash-report uploads
- No macOS support in version 1.0.2
- SAGA is not a replacement for Fusion Drawings, Fusion Animation, or an enterprise PLM system

### Installation

SAGA 1.0.2 is distributed through the [Autodesk Design and Make Marketplace](https://marketplace.autodesk.com/apps/ba97abb7-47a9-461d-a69e-a31130964c5a). Close Fusion before installing, updating, or uninstalling SAGA, then use the Marketplace-provided installer.

SAGA does not start automatically by default. After installation, start it from **Utilities > Scripts and Add-Ins > Add-Ins** in Fusion and use the SAGA toolbar command to reopen its palette during that Fusion session.
