# SAGA Release and Update Policy

**Effective date: August 5, 2026**

SAGA is sold as a one-time purchase. It is not a subscription.

A SAGA 1.0 purchase includes the version purchased and any 1.x maintenance updates that Shawn Gordon chooses to release. Maintenance updates may include defect fixes, compatibility corrections, security fixes, and small workflow improvements.

A purchase does not promise:

- Lifetime updates
- Support for every future Fusion release
- New features on a fixed schedule
- Free access to a future major version
- Continued support for obsolete SAGA or Fusion versions

## Fusion compatibility

Fusion changes over time. Reasonable efforts will be made to keep the current SAGA release compatible with supported Fusion updates, but some Autodesk changes may require investigation, a workaround, or a later SAGA update.

## Major versions

A future major release, such as SAGA 2.0, may be offered as a separate paid upgrade. Any upgrade price, eligibility, or discount will be announced before that release.

## Feature requests

Feature requests may be reviewed for future development, but they do not create a commitment, delivery date, or entitlement to implementation.

## Ending support for an older version

When support for an older version ends, notice will be posted in the release notes or Marketplace listing when practical. Ending support does not delete the installed software or the user's local project files.
